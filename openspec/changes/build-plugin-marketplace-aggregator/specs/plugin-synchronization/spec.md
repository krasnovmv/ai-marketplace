# Spec Delta

## Purpose

Синхронизация зеркалирует целые пакеты из точных ревизий и готовит проверенный набор без изменения пользовательской рабочей папки.

## ADDED Requirements

### Requirement: Разрешение ревизии и пакетов

Система SHALL разрешать branch каждого включённого источника в полный SHA один раз за запуск. Для marketplace SHALL читаться `.claude-plugin/marketplace.json`; в MVP поддерживаются строковые source с локальным путём в том же репозитории, включая `./`. Внешние URL и неподдерживаемые формы выбранного source SHALL приводить к ошибке, а не к неявной загрузке.

#### Scenario: Ветка сдвинулась

- **WHEN** upstream получил новый коммит после разрешения SHA
- **THEN** все выбранные пакеты этого источника читаются из первоначального SHA

#### Scenario: Неподдерживаемая запись в all

- **WHEN** целый marketplace содержит внешний source
- **THEN** запуск указывает проблемную запись и не публикует частичный набор

### Requirement: Исчезновение и перенос

При неизменной конфигурации исчезновение ранее зеркалируемого плагина, неоднозначное имя, отсутствие manifest/каталога или изменение сохранённого пути SHALL блокировать обновление всего набора. Это относится к all и selected. Явное исключение/отключение разрешает удаление; явная смена repository/type/path в config разрешает замену происхождения. Автоматический поиск переименований запрещён.

#### Scenario: Исчезновение в all

- **WHEN** ранее принятый пакет исчез из upstream manifest
- **THEN** отчёт показывает REMOVED как блокирующую ошибку; принятая копия остаётся

#### Scenario: Перенос

- **WHEN** путь в manifest изменился при прежнем config
- **THEN** отчёт показывает BROKEN со старым и новым путями без публикации

### Requirement: Зеркало без переписывания

Система SHALL копировать все обычные Git-файлы и проверенные внутренние symlink выбранного дерева в `plugins/<name>/`, сохраняя имена, байты, вложенность и Git mode. Ссылки SHALL сохранять исходный адрес и mode `120000`, без замены содержимым цели. На Windows временная рабочая копия SHALL использовать текст адреса ссылки как обычный файл, сохраняя тип ссылки в индексе Git; на платформах с нативными symlink создаётся ссылка. Локальная проверка SHALL учитывать оба представления; подтверждение поддержки ссылок настольным клиентом остаётся отдельной приёмкой. Навыки, hooks, manifest, скрипты, ресурсы и LICENSE/NOTICE/COPYING SHALL сохраняться. Отслеживаемые `dist`, `node_modules`, `.github` и другие каталоги SHALL не удаляться по имени. Git-служебные данные и локальные неотслеживаемые файлы не входят в поставку. Недопустимый файл SHALL вызывать отказ всему пакету, а не скрытое усечение.

#### Scenario: Нужный dist

- **WHEN** выбранный пакет содержит отслеживаемый dist и hook, который его использует
- **THEN** оба копируются без изменений и без запуска hook

#### Scenario: Плагин в корне репозитория

- **WHEN** source равен `./`
- **THEN** сохраняются отслеживаемые файлы корневого пакета; каталог .git и файлы локального cache не появляются в зеркале

### Requirement: Изоляция результата

Полный sync SHALL готовить результат в отдельной копии репозитория, проверять его целиком и помечать пригодным к публикации только после успеха. Рабочая папка, индекс и ветка вызывающего пользователя SHALL оставаться неизменными. Ошибка копирования/проверки SHALL не менять default branch, bot-ветку или существующий PR. Замена произвольного пользовательского дерева на месте не поддерживается.

#### Scenario: Сбой одного пакета

- **WHEN** из трёх пакетов один не прошёл проверку
- **THEN** ни один пакет не публикуется, исходное рабочее дерево неизменно

#### Scenario: Сбой записи в копии

- **WHEN** запись результата прервалась
- **THEN** копия помечается неуспешной и не публикуется; запуск можно повторить с чистой копией

#### Scenario: Чужие файлы

- **WHEN** в целевом управляемом пути обнаружен файл без принадлежности принятому набору
- **THEN** обновление отказывается его перезаписывать и сообщает конфликт
