# Proposal

## Why

Нужен личный GitHub-каталог, из которого можно устанавливать выбранные внешние плагины в локальные Claude Desktop и ChatGPT. Зеркало сохраняет исходные пакеты без исправления навыков, а обновления принимает через проверяемые PR с минимумом ручных действий.

## What Changes

- Ввести два явно выбираемых режима источника: весь маркетплейс (`all`) или конкретные плагины (`selected`). Размер источника автоматически не определяется.
- Начать с маркетплейсов `DietrichGebert/ponytail` и `mattpocock/skills` в режиме `all`. OpenSpec не входит в зеркало; его CLI остаётся отдельным инструментом разработки этого проекта.
- Копировать пакеты целиком в `plugins/`, сохраняя содержимое и исходные версии. Не переписывать инструкции, hooks или другие компоненты ради совместимости.
- Хранить происхождение принятой копии и хеш её файлов в `metadata/`. Проверять пути, структуру и целостность без исполнения кода плагинов. Разрешить относительные symlink на файлы внутри пакета с проверкой всей цепочки; сохранять адрес и Git mode ссылки без раскрытия.
- Генерировать каталоги для обоих настольных клиентов с локальными ссылками на одни и те же копии. Установку и получение обновления проверять отдельно в каждом приложении.
- Ежедневно и по ручному запуску готовить полный результат в отдельной копии репозитория. Публиковать один общий PR; принятие остаётся ручным.
- Создавать автоматический PR при добавлении, удалении или изменении файлов выбранных пакетов. Смена upstream SHA без изменения пакета не меняет принятую metadata и не создаёт коммит.
- Для локальной работы оставить проверку и предпросмотр; полноценный запуск готовит отдельную копию, сохраняя рабочую папку пользователя.

Новые плагины в режиме `all` и новые навыки внутри выбранного пакета включаются в предложение обновления и попадают в основную ветку только после принятия PR. В режиме `selected` новые соседние плагины не импортируются.

Не входят в первую версию: собственная упаковка OpenSpec, исправление плагинов, эмуляция возможностей клиентов, универсальная система адаптеров, алиасы, overrides, dashboard, policy engine, автоматическое слияние PR и публикация релизов.

## Capabilities

### New Capabilities

- `source-configuration`: источники GitHub, режимы all/selected, отключение и уникальность имён.
- `plugin-synchronization`: точные ревизии, копирование целых пакетов и подготовка результата вне рабочей папки.
- `plugin-validation`: безопасное чтение недоверенных пакетов без исполнения и автоматической починки.
- `plugin-provenance`: происхождение принятой копии, хеш файлов и отсутствие изменений только ради SHA.
- `marketplace-generation`: каталоги для Claude Desktop и ChatGPT desktop, проверка установки и обновления.
- `sync-cli`: локальная проверка, предпросмотр и подготовка отдельной копии.
- `update-automation`: ежедневный sync, проверка PR и ручное принятие обновлений.

### Modified Capabilities

Нет: действующих спецификаций приложения ещё нет.

## Impact

Будут добавлены `config/upstreams.json`, `plugins/`, `metadata/`, `.claude-plugin/marketplace.json`, `.agents/plugins/marketplace.json`, команды Node.js и два workflow GitHub Actions. Планируемый стек: Node.js 22+, ESM JavaScript, npm и Git; стандартная библиотека покрывает базовые операции. README опишет настройку зеркала, подключение обоих клиентов и обновление установленных копий. Существующие `.agents/skills/` и инструкции агентов не относятся к генерируемым данным.
