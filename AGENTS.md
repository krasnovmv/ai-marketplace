# Работа над marketplace

Общие инструкции для Codex и Claude Code. Меняйте правила здесь; `CLAUDE.md` импортирует этот файл.

## Контекст

Проект начинается с пустого репозитория. Стек и требования к продукту пока не определены.
Перед первой реализацией уточните назначение продукта и ограничения, влияющие на выбор стека.
Когда появится приложение, обновите README: назначение, установка, запуск и проверка.

## Порядок работы

- Отвечайте пользователю по-русски.
- Перед изменениями прочитайте README, проверьте `git status` и изучите затрагиваемый код вместе с его вызывающими участками. Сохраняйте чужие незавершённые изменения.
- Выбирайте минимальное решение: существующий код, стандартная библиотека, возможности платформы, затем уже установленные зависимости. Добавляйте новые зависимости только при конкретной необходимости.
- При исправлении ошибки найдите общую причину и добавьте минимальную проверку, воспроизводящую её.
- Команды запуска и проверки берите из конфигурации проекта. Выполните проверки, относящиеся к изменениям; если их нет или они недоступны, явно сообщите об этом.
- Храните секреты вне Git. В примерах конфигурации используйте только фиктивные значения.
- В итоговом ответе кратко укажите результат, выполненные проверки и оставшиеся ограничения.
