# marketplace

Репозиторий подготовлен для работы с Claude Code и Codex.
Стек и требования к продукту пока не определены; приложения и команд проверки ещё нет.

Откройте корень репозитория в Codex или запустите Claude Code из этой папки.
Общие правила находятся в [AGENTS.md](AGENTS.md); [CLAUDE.md](CLAUDE.md) импортирует их.
Обновляйте общие инструкции только в AGENTS.md.

После добавления приложения укажите здесь его назначение и команды установки, запуска и проверки.

Формат инструкций: [документация Codex](https://developers.openai.com/codex/guides/agents-md)
и [документация Claude Code](https://code.claude.com/docs/en/memory).
